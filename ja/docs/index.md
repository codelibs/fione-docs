# リファレンスの概要

リファレンスでは、Fione の設定、実行、運用を説明します。作業手順に沿った説明は[ガイド](/ja/guide/)を参照してください。

## リファレンスのページ

| ページ | 内容 |
|---|---|
| [設定](/ja/docs/configuration) | すべての設定。Fione の設定、Docker Compose の変数、Fione Serving と `fione-sdk` の変数、リバースプロキシ、セットアップトークン、秘密鍵、一時領域、ストレージ。 |
| [Fione Serving](/ja/docs/serving) | 学習済みモデルを予測 API として動かす方法。イメージ、`POST /invocations` (寄与を含む)、`GET /model`、`GET /ping`、モデルファイルと信頼。 |
| [REST API](/ja/docs/rest-api) | スクリプトやほかのプログラム向けの `/api/v1` API と API トークン。 |
| [アシスタントの設定と MCP](/ja/docs/assistant) | 言語モデル (Ollama または Claude) の接続、管理者の確認、送られるデータ、上限、MCP エンドポイント、トラブルシューティング。 |
| [停止・バックアップ・更新](/ja/docs/operations) | Fione のインストールを長く運用する方法。 |
| [既知の制限](/ja/docs/known-limitations) | Fione ができないこと、制限つきでしかできないこと。 |

## アーキテクチャ

Fione のインストールは、1 つのアプリケーションと、その周りのいくつかのサービスでできています。

**Web アプリと API。** `fione` という 1 つのコンテナが、Web UI、REST API (`/api/v1`)、オプションの MCP エンドポイント (`/mcp`) をポート 8080 で、単一の uvicorn プロセスとして提供します。ジョブキューも同じプロセスにあります。ユーザーはユーザー名とパスワードでサインインし、管理者・編集者・閲覧者の 3 つのロールのいずれかを持ちます。スクリプトは API トークンを使います。サインインの制限、アップロードの上限、ジョブランナーはそのプロセスのメモリ上にあるため、Fione はワーカープロセスをちょうど 1 つで動かします ([設定](/ja/docs/configuration)を参照)。

**ジョブランナー。** 学習、予測、説明、モデルのエクスポート、Python モジュールはジョブとして実行されます。ランナーはキューのジョブを取り出し、それぞれを専用のワーカープロセスで開始するので、クラッシュしたり中止されたりしたジョブが Web アプリを巻き込むことはありません。既定では学習が 1 つずつ動き、その横で最大 4 つのほかのジョブが動きます。ワーカーの中の AutoML エンジンは、設定した実行時間の範囲で、勾配ブースティング、ランダムフォレスト、線形モデル、ニューラルネットワークを学習し、上位のモデルをアンサンブルします。

**SQLite のメタデータ。** ユーザー、プロジェクト、データセット、ジョブ、モデル、アシスタントの会話は、データディレクトリ (Compose の構成では `fione-data` ボリューム) の SQLite データベース (`fione.db`) の行として保存されます。データディレクトリには、秘密鍵、ジョブのログ、一時ファイルもあります。

**オブジェクトストレージ。** データセットのファイルと学習済みモデルはオブジェクトとして保存されます。Compose は、このために S3 API を持つ SeaweedFS を動かし、バケットは `fione` コンテナが最初の起動時に作成します。S3 互換のサービスなら何でも使え、ローカルのディレクトリで代用することもできます。ストレージに接続するのは `fione` コンテナだけです。

**Fione Serving。** 学習済みモデル 1 つを HTTP で提供する、独立した小さなイメージです。モデルをサービング用ファイルとしてダウンロードし、そのイメージで動かします。Fione もストレージも必要とせず、専用の Compose ネットワークで動きます。[Fione Serving](/ja/docs/serving)を参照してください。

**言語モデル (オプション)。** アシスタントは言語モデルのサーバーを呼びます。Ollama サーバー (ホスト上、または `ollama` プロファイルで Compose 内) か、Anthropic API 経由の Claude です。何も同梱されておらず、Fione はなくても動きます。[アシスタントの設定と MCP](/ja/docs/assistant)を参照してください。

```text
 ブラウザ / スクリプト / MCP クライアント
            |
            v
   +--------------------+        +----------------------+
   | fione              | -----> | SeaweedFS (S3)       |
   |  Web UI, REST API, |        | データセットとモデル |
   |  ジョブランナー    |        +----------------------+
   |  --> ワーカー      |
   |  SQLite (fione.db) | -----> 言語モデル (オプション)
   +--------------------+        Ollama または Claude

   fione-serving: モデル 1 つ、専用ネットワーク
```
