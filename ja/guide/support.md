# ヘルプとサポート

Fione は Apache License 2.0 のオープンソースソフトウェアです。個人・商用を問わず無料で利用できます。

## 質問する

[Fione フォーラム](https://discuss.codelibs.org/c/fioneja/)で質問してください(英語で質問するときは[英語のフォーラム](https://discuss.codelibs.org/c/fioneen/))。使っているバージョン、行ったこと、表示された内容を書いてください。データ、ホスト名、API トークンは書かないでください。

## 不具合を報告する・改善を提案する

[GitHub](https://github.com/codelibs/fione/issues) に Issue を作成してください。不具合のときは、再現手順とログの該当部分(`docker compose -f docker/compose.yaml --env-file docker/.env logs fione`)を、秘密の値を消したうえで添えてください。プルリクエストも歓迎します。

## 使い方を共有する

Fione で役に立つ予測ができたら、フォーラムで紹介してください。何を、どのデータから予測し、予測をどう使っているかがわかると、次に使う人が自分の課題に Fione が合うかを判断しやすくなります。

## 商用サービス

Fione の開発元である株式会社コードリブズが、Fione の商用サービスを提供しています。[codelibs.co の Fione のページ](https://codelibs.co/ja/product/fione.html)をご覧ください。
