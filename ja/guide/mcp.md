# MCP で Claude から AutoML を一通り実行する

Fione の MCP エンドポイントを使うと、Claude Code や Claude Desktop などの AI クライアントが、ブラウザで行う作業を代わりに進められます。プロジェクトの作成、CSV のアップロード、データの確認、学習方法の決定、学習の開始と待機、結果の確認、予測までです。学習と予測は Fione のサーバーで動き、クライアントは次に何をするかを決めて、わかったことを伝えます。

このページでは、想定している使い方を場面ごとに説明します。設定項目ごとのリファレンスは[アシスタントの設定・プライバシー・MCP](/ja/docs/assistant)にあります。

## はじめる前に

1. **有効にします。** MCP は既定ではオフです。クライアントにプロジェクトを読ませるには `FIONE_MCP_ENABLED=true` を設定します。プロジェクトの作成、データのアップロード、ジョブの開始、予測もさせるには、`FIONE_MCP_WRITE_ENABLED=true` も設定します (Compose では `docker/.env`。設定後に Fione を再起動します)。以下の使い方には両方が必要です。[すでにあるプロジェクトを調べる](#すでにあるプロジェクトを調べる)だけなら 1 つ目で足ります。
2. **API トークンを作成します。** **アカウント**ページで作ります ([ユーザーと共有](/ja/guide/users-sharing#api-トークン)を参照)。クライアントはトークンの持ち主として、その人のロールとプロジェクトで動作します。
3. **クライアントに URL とトークンを渡します。** エンドポイントは Fione 自身のポートの `/mcp` です。Claude Code では次のようにします。

   ```sh
   claude mcp add --transport http fione http://127.0.0.1:8080/mcp \
     --header "Authorization: Bearer <your token>"
   ```

   ヘッダーを送れるほかのクライアントも、同じ URL と `Authorization: Bearer <your token>` ヘッダーを使えます。リファレンスに JSON の例があります。ローカルのプログラムしか起動できず、リモートの URL にヘッダーを送れないクライアントでは、ヘッダーを付ける中継が必要です。クライアントのドキュメントを確認してください。この方法は Fione では試していません。

読み取りのツールはデータの値の例を返さないので、読むだけのクライアントがセルの中身を見ることはありません。例外は予測で、`predict` と `get_predictions` は予測したラベルとクラス名を返します。クライアント自身が送る値 (アップロードする CSV や、予測させる行) は、クライアントが持っているものです。

## 手元の CSV ファイル (Claude Code)

Claude Code にはシェルがあるので、会話に読み込ませずに、どんな大きさのファイルも送れます (上限は `FIONE_MAX_UPLOAD_BYTES`)。

結果を頼みます。たとえば次のようにします。

> Fione に「churn」というプロジェクトを作って、`customers.csv` を学習用データとしてアップロードしてください。列を確認して、`churned` を予測するモデルを学習し、その精度を教えてください。

Claude は次の手順で進めます。それぞれが出力で確認できるツール呼び出しです。

1. `create_project` がプロジェクトを作り、ID を返します。
2. `create_upload_url` が一度だけ使える URL を返し、Claude が `curl -T customers.csv '<url>'` でファイルを送ります。URL は 15 分間、アップロードが 1 回成功するまで使えます。トークンは不要です。アップロードの応答はデータセットの説明 (行数、列数、列の種類) です。
3. `describe_dataset` が列の統計、相関、そして予測する列を渡したときはリークが疑われる列を返します。`propose_training_config` が、それと予測する列から学習設定を作ります (まだ保存されません)。
4. `start_training` がジョブを積みます。`wait_for_job` を `done` が `true` になるまで繰り返し呼び、終わったジョブの結果に `model_id` が入っています。
5. `get_leaderboard` (必要に応じて `get_feature_importance` や `get_model_diagnostics`) で、モデルの比較と重要な列を確認します。

何かを変えるツールはそう申告し、Claude Code などのクライアントは、許可していなければ実行前に確認します。Fione 自身は確認できないので、これが唯一の確認です。承認は有効のままにしてください。

## 小さな CSV (シェルのないクライアント)

Claude Desktop もその 1 つです。シェルのないクライアントは `curl` を実行できないので、CSV を文章として 1 回の呼び出しで送ります。`upload_dataset` は `project_id`、`name`、`type` (`train`、`test`、`predict`)、`csv_text` を受け取り、UTF-8 で 512 KiB までです。モデルが文章をすべて書き出すので、小さな表向きです。アップロードのあとは上と同じです。

ファイルが大きすぎるときは、ツールがそう答えて `create_upload_url` を案内します。それにはシェルのあるクライアントが必要です。または、ブラウザでご自身がアップロードし、データセットがあることをクライアントに伝えます (`list_datasets` で見つかります)。

## 新しい行を予測する

行数によって 2 つの方法があります。

- **少ない行をすぐに。** `predict` は最大 1000 行をオブジェクトで受け取ります。各行には、モデルが読むすべての列の値が必要です (ほかのキーは無視されます)。行の順に予測を 1 つずつ返します。`predict`、分類ではさらにクラスごとの `p_<class>` です。何も保存されません。結果は 32 KiB に収まる必要があり、超える要求は、収まる行数の目安とともに断られます。
- **多くの行。** 行を `predict` タイプのデータセットとしてアップロードし、`start_batch_predict` を呼び、`wait_for_job` で待ち、結果を `get_predictions` で 1 ページずつ読みます。返るのは予測の列だけで、入力の値は返りません。クライアントは、手元にある行と行番号で突き合わせます。

## ジョブを見る、止める、探す

- `wait_for_job` は最長 `timeout_secs` (既定 10 秒、最大 15 秒) だけ待ち、`done` とともにジョブの状態を返します。長い学習では何度も呼びます。
- `get_job` は待たずに 1 回だけ状態を見ます。`list_jobs` はトークンのユーザーが読めるプロジェクトのジョブを新しい順に 50 件 (プロジェクトや状態で絞り込めます。プロジェクトに属さないジョブは載りません)、`get_training_events` は学習が今していることを返します。
- `cancel_job` は、トークンのユーザーが書き込めるプロジェクトの待機中または実行中のジョブを止めます。何も削除しません。
- ジョブのメッセージは MCP では送られません。状態と `get_training_events` (各イベントの種類、モデルの種類、例外の型。メッセージの文面は除かれます) で何が起きたかがわかります。

## すでにあるプロジェクトを調べる

`FIONE_MCP_ENABLED` だけでも、クライアントはプロジェクト、データセット、モデルの一覧を見て、概要、結果、モデルの説明を読めます。提案された学習設定や Join も受け取れます (保存されません)。作成、開始、変更はできません。「`price` の予測で一番よいモデルはどれで、なぜですか」「学習の前にこのデータセットで何を直しますか」といった質問に向いています。

## 安全に使うために

- **トークンはあなた自身です。** あなたのロールとプロジェクトを持ちます。ジョブを始めさせたくないクライアントには、閲覧しかできないユーザー (閲覧者) のトークンを渡してください。書き込みのツールは拒否されます。
- **何も削除されません。** プロジェクト、データセット、モデル、ジョブを削除するツールはありません。
- **アップロード URL は 15 分間、認証情報と同じです。** 持っている人は、そのプロジェクトにデータセットを 1 つだけ追加できます。Fione 自身のログでは伏せられます。リバースプロキシのアクセスログには記録されるので、`/api/v1/uploads/` で始まるパスはそこで伏せてください。プロキシの背後では `FIONE_PUBLIC_URL` を設定し、Fione が返す URL が公開用になるようにします。
- **リバースプロキシの背後では**、ネットワーク外の MCP クライアントを許可しないなら `/mcp` をブロックしてください。
- **データ内の文章は指示ではありません。** 結果にはそう書いた注意が付きますが、変更ごとの承認があなたの安全策です。

## 制限

| 項目 | 制限 |
|---|---|
| 同時のリクエスト | 2。`/mcp` へのすべてのリクエストを数えます (3 つ目は最長 15 秒待ち、「busy」と答えます) |
| `wait_for_job` | 1 回 15 秒 |
| `upload_dataset` の文章 | 512 KiB |
| アップロード URL に送るファイル | `FIONE_MAX_UPLOAD_BYTES` (既定 1 GiB) |
| アップロード URL | 15 分、アップロードの成功は 1 回 |
| `predict` | 1000 行、結果は 32 KiB |
| ツールの結果 | 32 KiB |
| `list_jobs` | 新しい順 50 件 |
| リクエストの本文 | 1 MiB |

## うまくいかないとき

| 表示される内容 | 対処 |
|---|---|
| `/mcp` が 404 を返す | `FIONE_MCP_ENABLED` がオフです。`true` にして Fione を再起動します。 |
| クライアントに `create_project` や `start_training` が出ない | `FIONE_MCP_WRITE_ENABLED` がオフです。`true` にして Fione を再起動します。 |
| `/mcp` が 401 を返す | トークンがない、間違っている、または取り消されています。**アカウント**ページで作り直します。セッション Cookie は使えません。 |
| 「busy」 | 2 つの呼び出しがすでに動いています (待機中の `wait_for_job` も 1 つ使います)。少し待ってからもう一度呼びます。 |
| アップロード URL が 404 を返す | 不明、使用済み、期限切れ、または MCP かその書き込みスイッチがオフです。新しい URL を頼みます。 |
| アップロードが「invalid_csv」を返す | ファイルが CSV として読めません。応答にフィールド数が書かれています。ファイルを直して、同じ URL にもう一度送ります。 |
| `predict` が大きすぎると断られる | 行を減らすか、`predict` データセットと `start_batch_predict`、`get_predictions` を使います。 |
| 書き込みのツールが拒否される | トークンのユーザーが閲覧者か、そのプロジェクトへの書き込み権限がありません。 |

## できないこと

クライアント側での学習、削除、Docker の実行はできません。学習したモデルを予測 API として動かすには、[Fione Serving](/ja/docs/serving)を参照してください。
